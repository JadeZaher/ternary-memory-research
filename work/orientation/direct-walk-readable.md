🏃
RUN
Run the agent time
Proof of Time
Two orbs — Swordsman (coral) and Mage (teal) — wander the spellweb in a 35-pixel orbit. Each traversal of the marked constellation is one lap. Each lap accumulates behavioural density ρ — micro-variations in timing, attention, intention. ρ is the privacy amplifier: more laps, denser proof. The orbs cannot be delegated, the path cannot be reversed.
ρ = f(traversal_depth, temporal_duration, intentional_transitions)
✨
E
Evoke the constellation
Proof of Path
The visitor hits evoke. The constellation locks: a SHA-256 commitment of the node sequence + nonce stores onchain. No nodes added or removed during evocation — the path was chosen before the walk began. Swordsman fixes the boundary before Mage projects through it. The Forge phase later reveals the (hash, nonce) pair to verify.
commitment = SHA-256(constellation_hash + nonce)
⚒️
CRAFT
Craft the forge and blades
Proof of Sovereignty
Six dimensions activate based on what the constellation actually touched. Hex crystallises into one of 2⁶ = 64 states. Key signs. Blade materialises — a cryptographic artifact carrying the time you spent, the path you traced, and the sovereignty posture you earned. UOR × 64-Tetrahedra × ZK convergence.
HEXAGRAM = Z/(2⁶)Z · STRIKE = neg(bnot(vertex))
